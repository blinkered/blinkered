# Licence texts

The verbatim text of every licence a shipped word list is distributed under. Referenced by
each language's `LICENSE` rather than copied sixteen times.

`GPL-3.0.txt` is here only because `LGPL-3.0` is written as a set of additional permissions on
top of it and cannot be read without it. **No Blinkered word list is distributed under the
GPL**, and no GPL-licensed dictionary was used to build one: see the licence audit in
`tools/dictionary/src/manifest.ts`, and the reasoning in `docs/DICTIONARIES.md`.

Sources: [spdx/license-list-data](https://github.com/spdx/license-list-data), fetched
2026-08-26.
